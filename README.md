# notopened 1일 1상식 두뇌 퀴즈

설치나 회원가입 없이 브라우저에서 바로 5문항 상식 퀴즈를 풀고, 결과를 공유할 수 있는 정적 웹 앱입니다.

- 서비스 주소: https://notopened.com/quiz/
- 공개 버전: v6.3 (오늘의 챌린지·오답 노트·누적 약점·연속 정답 콤보·키보드 단축키, 2026-11-28)
- 제작: notopened AI ENTERPRISE

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 오늘의 5문항 챌린지 | `?daily=1` 로 KST 날짜 시드에 고정된 5문항에 도전합니다. 메인 카드에 오늘 기록·연속 참여 일수·내일 예고가 표시되고, 결과 공유 문구와 이미지에 날짜가 들어갑니다. |
| 오답 노트 | 결과 화면에서 틀린 문항의 내 선택·정답·해설·출처를 접었다 펼치고, 가장 많이 틀린 주제로 바로 재도전합니다. 주제별 오답 누적은 메인 '약점 주제' 칩으로 표시됩니다. |
| 연속 정답 콤보 | 정답이 이어지면 해설에 '🔥 N연속'이 표시되고, 최고 콤보를 기록합니다. |
| 키보드 단축키 | 데스크톱에서 1~4 키로 선택지, Enter로 다음 문제를 진행합니다. |
| 미풀이 우선 출제 | 같은 브라우저로 다시 오면 아직 풀지 않은 문항부터 5문항씩 출제합니다(`localStorage` 기록). |
| 60문항 순환 | 문항 60개를 모두 풀면 "모든 60문항 완주! 새 순환을 시작합니다" 안내와 함께 기록을 초기화하고 새 순환을 시작합니다. |
| 도전 기록 | 연속 도전 일수·누적 풀이·최고 점수를 메인과 결과 화면에 표시합니다. |
| 주제 딥링크 | `?cat=science`, `?cat=history`, `?cat=world`, `?cat=health`, `?cat=nature`, `?cat=life`, `?cat=tech` 로 해당 주제 문항부터 시작합니다. |
| 다른 콘텐츠 연결 | 바둑·체스 한 수, 사주·꿈풀이·MBTI 궁합, YouTube 채널로 이어지는 링크를 제공합니다. |
| 제휴 배너 | 화면 하단에 쿠팡 파트너스 다이나믹 배너(680×140)를 화면 폭에 맞춰 축소해 표시합니다. 배너가 로드될 때만 영역이 보이고, 공정위 문구를 함께 표시합니다. |

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 퀴즈 화면 (기록 요약·주제 선택·진행률·문항·결과·공유·패밀리 웹·제휴 배너) |
| `privacy.html` | 개인정보처리방침 (`localStorage` 기록 범위·쿠팡 파트너스 제휴 배너 안내 포함) |
| `src/app.js` | 출제·채점·기록 저장·주제 딥링크·결과 공유 로직 |
| `src/data.js` | 검증된 상식 문항 60개 데이터와 주제(`slug`) 7종 정의 |
| `src/touchHandler.js` | 모바일 터치 피드백 처리 |
| `assets/css/style.css` | 화면 스타일 |
| `assets/og-image.png` | 공유용 미리보기 이미지 |
| `sitemap.xml` | 사이트맵 |
| `robots.txt` | 검색 로봇 안내 |
| `QA.md` | 공개 검사 항목과 실측 결과 |

빌드 과정이 없는 정적 사이트이며, `main` 브랜치 루트가 그대로 GitHub Pages로 게시됩니다. 외부에서 불러오는 스크립트는 하단 쿠팡 파트너스 제휴 배너(`ads-partners.coupang.com/g.js`) 하나뿐이고, 애드센스 등 그 밖의 광고 코드·자체 추적 도구·서버 호출은 넣지 않았습니다.
