# notopened 1일 1상식 두뇌 퀴즈 포털

유튜브 숏폼과 연동되는 30초 스낵 상식 퀴즈 웹 앱입니다. 설치나 회원가입 없이 브라우저에서 바로 5문항 세트를 풀고, 결과를 공유할 수 있습니다.

- 서비스 주소: https://penta309.github.io/notopened-quiz/
- 공개 버전: v1.2.2-patch3 (화면 표기 v1.2.2)
- 제작: notopened AI ENTERPRISE

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 퀴즈 화면 (진행률·문항·결과·공유) |
| `privacy.html` | 개인정보처리방침 |
| `src/app.js` | 퀴즈 진행·채점·결과 공유 로직 |
| `src/data.js` | 검증된 상식 문항 30개 데이터 |
| `src/touchHandler.js` | 모바일 터치 피드백 처리 |
| `assets/css/style.css` | 화면 스타일 |
| `QA.md` | 공개 검사 항목과 실측 결과 |

빌드 과정이 없는 정적 사이트이며, `gh-pages` 브랜치가 그대로 GitHub Pages로 게시됩니다. 외부 스크립트·추적 도구·광고 코드는 포함하지 않습니다.
